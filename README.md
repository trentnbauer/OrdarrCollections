# OrdarrCollections
Community managed collections for the Ordarr app

## MCU main timeline

[View the collection](mcu-main-timeline.yaml) · [Raw YAML for Ordarr](https://raw.githubusercontent.com/trentnbauer/OrdarrCollections/main/mcu-main-timeline.yaml)

One main-timeline MCU collection with films, canon series, shorts and specials in
chronological story blocks. Alternate-universe stories are excluded. Scope and
sources are recorded in the YAML comments.

## Contributions

Add or update a version 1 Ordarr YAML/JSON collection and open a pull request.
The **Validate collection files** check runs Ordarr's actual import parser on every
collection, checks expanded entry limits and rejects duplicate collection IDs.
It validates file structure and identifiers, not factual watch-order accuracy.

See Ordarr's [portable-format guide](https://github.com/trentnbauer/Ordarr/wiki/Portable-format)
for the supported schema. Never include service credentials or server configuration.
